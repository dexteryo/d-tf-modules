`.clever/` is untracked (`git status`), and `.gitignore` ignores `ralph`. The identifier guard skips any path containing `.clever` (`scripts/check-no-foreign-identifiers.sh:39`).

## Module folder shape

Every module has the same skeleton:

```text
modules/<name>/
├── versions.tf          terraform + required_providers only
├── variables.tf         every input, with description, type, default and validation blocks
├── main.tf              locals + resources (the whole module when it is small)
├── outputs.tf           every output with a description
├── README.md            hand-written sections + terraform-docs block
├── examples/basic/main.tf   a root config calling source = "../.." with its own terraform/provider blocks
└── tests/<name>.tftest.hcl  terraform test suite with mock_provider "aws"
```

Larger modules split `main.tf` by concern:

| Module | Extra files |
| --- | --- |
| `ecs-service` | `locals.tf` (data sources, container definitions, IAM statements), `iam.tf` (roles and policies) |
| `rds-postgres` | `roles.tf` (random passwords and per-role secrets), `proxy.tf` (RDS Proxy and its role) |
| `vpc` | `endpoints.tf`, `flow_logs.tf` |
| `cloudfront-spa` | `backends.tf` (VPC-origin behaviours and functions), `access_logs.tf`, `functions/spa-rewrite.js` |

Test file names are not uniform: most use snake case (`ecs_service.tftest.hcl`, `ci_oidc_role.tftest.hcl`), while the three newest use the module's hyphenated name (`acm-certificate.tftest.hcl`, `cloudfront-spa.tftest.hcl`, `waf-web-acl.tftest.hcl`).

## Dependencies between modules (inside this repository)

Only two modules call another module by relative path:

| Caller | Callee | How |
| --- | --- | --- |
| `modules/alb` | `../security-group` | always, with `name_suffix = "alb"` (`modules/alb/main.tf:38-50`) |
| `modules/ecr` | `../kms` | when `create_kms_key = true` (default) (`modules/ecr/main.tf:35-42`) |

Every other relationship is wiring done by the caller through outputs and inputs (see `architecture.md`). `modules/vpc` creates its endpoint security group directly with `aws_security_group` rather than through `../security-group` (`modules/vpc/endpoints.tf:1-7`).

Examples reference modules by relative path: `examples/basic` uses `source = "../.."` (plus `../../../tags`, `../../../kms` and others where needed), `examples/ordering-agent` uses `../../modules/<name>`.

## Generated content

The block between `<!-- BEGIN_TF_DOCS -->` and `<!-- END_TF_DOCS -->` in each module README is generated by terraform-docs (`.terraform-docs.yml`, `mode: inject`, sorted by required first). CI fails when it drifts (`scripts/check.sh`, step "terraform-docs", `--output-check`). Edit only the hand-written sections above it.
